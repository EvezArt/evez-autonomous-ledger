# Reality Drift Protocol

The system has two identities that must never be silently conflated:

- Steven Crawford-Maggard: operator.
- EVEZ: project/system identity.

The Event Spine is the evidence record. Agent output is not evidence merely because
an agent produced it.

Every consequential statement is classified before it can influence an external
effect:

    OBSERVATION
    VERIFIED_FACT
    SUPPORTED_INFERENCE
    HYPOTHESIS
    FICTION
    NARRATIVE
    UNKNOWN

The runtime interrupt is deliberately boring:

> DRIFT DETECTED
> Claim exceeds evidence.
> Return to observable state.
> What happened?
> What changed?
> What is recorded?
> What remains unknown?
> What can be reproduced?

Rules:

1. VERIFIED_FACT and SUPPORTED_INFERENCE require evidence or event references.
2. SUPPORTED_INFERENCE must be reproducible to remain actionable.
3. HYPOTHESIS, FICTION, NARRATIVE, and UNKNOWN may be recorded but cannot authorize
   consequential external effects.
4. Narrative language is not promoted to fact without an explicit evidence class.
5. Agent identity is not proof of consciousness, intention, coordination, or ontology.
6. Operator identity and project identity remain separate.
7. A blocked claim remains evidence of the block. It is not evidence for the claim
   that caused the block.
8. Unknown remains UNKNOWN. Silence, failure, or missing records do not automatically
   prove suppression, conspiracy, impunity, or intent.

This protocol does not determine whether a claim is true. It determines what the
system is permitted to treat as true enough for the requested operation.
